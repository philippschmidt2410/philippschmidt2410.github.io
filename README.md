# Philipp Schmidt — academic website

A bilingual English/German personal website for Philipp Schmidt, PhD student in Economics at LMU Munich.

## Local preview

Open `index.html` directly in a browser, or run a local server from the repository root:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages

This is a static site and can be published from the `main` branch through **Settings → Pages → Deploy from a branch**. The expected user-site URL is:

`https://philippschmidt2410.github.io`
